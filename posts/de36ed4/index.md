# Cloudflare常用工具以及产品介绍


Cloudflare 提供从基础的网站加速、安全防护，到进阶的开发者工具等一系列产品。其免费套餐就包含许多强大功能。

<!--more-->

### **网站性能与安全 (核心服务)**
这是Cloudflare最广为人知的基础服务，旨在提升网站速度与安全性。

*   **内容分发网络 (CDN)**：**核心功能**。通过全球节点缓存内容，显著提升网站访问速度。
*   **DNS 服务**：提供快速、可靠且免费的权威DNS解析服务。
*   **DDoS 防护**：自动防护各种规模和类型的分布式拒绝服务攻击。
*   **Web 应用防火墙 (WAF)**：防护SQL注入、跨站脚本等常见Web应用攻击。
*   **SSL/TLS 证书**：提供免费的 Universal SSL 证书，实现全站HTTPS加密。

### **开发者与存储工具**
这些工具为开发者提供了在Cloudflare全球网络上构建应用的能力。

*   **Cloudflare Workers**：**强大的无服务器计算平台**。允许在边缘节点运行JavaScript或Python代码，用于API代理、请求改写、构建轻量应用等。
*   **R2 存储**：**对象存储服务**。最大亮点是**零出口流量费**（下载不产生带宽费用），存储成本也低于AWS S3等。
*   **Cloudflare Tunnel (通过 cloudflared)**：**内网穿透与安全访问工具**。无需公网IP或开放路由器端口，就能安全地将本地服务（如NAS、Web应用）暴露到互联网，并可结合Zero Trust规则进行访问控制。

### **网络与零信任安全**
这些产品专注于更高级别的网络安全和访问控制。

*   **Zero Trust Network Access (ZTNA)**：零信任网络访问服务，替代传统VPN，基于身份和上下文保护对内部应用的访问。
*   **Cloudflare Access**：作为ZTNA的一部分，可为内部应用（如OA系统、项目管理工具）设置基于身份验证的访问门户。
*   **安全服务边缘 (SSE)**：整合了安全Web网关、数据防泄露、云访问安全代理等功能的一体化安全解决方案。

### **其他实用工具与付费服务**
除了上述类别，Cloudflare还有一些广受好评的独立产品。

*   **Email Routing**：**免费域名邮箱路由**。可以为你的域名创建无限别名，所有邮件自动转发至你的主邮箱，有效保护真实地址。
*   **Stream**：**视频存储与流媒体服务**。提供上传、编码、存储和自适应码流播放的一站式解决方案。
*   **Workers AI**：**边缘AI推理服务**。允许通过API直接在Cloudflare的边缘节点运行AI模型（如Llama文本生成），无需管理GPU。
*   **Argo Smart Routing**：**智能路由**。付费服务，通过实时分析网络状况，为你的流量选择最优路径，进一步提升速度与可靠性。

**常用命令行工具：Cloudflared**
这是Cloudflare官方命令行工具，主要用于创建和管理 Cloudflare Tunnel，也支持DNS over HTTPS (DoH) 等功能。

### **如何选择与使用？**
你可以根据自己的需求来组合使用这些工具：

*   **如果你是个人开发者或站长**：强烈建议从**免费套餐**开始，它几乎包含了所有核心服务（CDN、WAF、SSL、 Workers每日限额、R2存储限额等），功能已非常强大。
*   **如果你想安全地公开本地项目**：组合使用 **`Cloudflare Tunnel`** (通过 **`cloudflared`** 工具部署) 和 **`Access`**，可以零成本实现安全的内网穿透和访问控制。
*   **如果你需要构建无服务器API或处理AI任务**：**`Workers`** 和 **`Workers AI`** 是绝佳选择，能让你在边缘网络快速部署轻量级应用和AI功能。
*   **如果你想大幅降低存储文件的带宽成本**：**`R2 存储`** 的零出口流量费特性非常有吸引力，尤其适合图床、软件下载等场景。

总的来说，Cloudflare已从一个CDN服务商，发展成了一个功能丰富的**边缘计算与安全平台**。建议你先明确自己的核心需求（如加速、安全、开发），然后从对应的免费产品入手体验。
